# Changelog

## 1.0.0 — 2026-10-07

- Initial public release.
- Weighted present and absent evidence from up to twelve named sources.
- Independent report lifetimes with active, missing and stale source summaries.
- Configurable consensus thresholds and deterministic conflict handling.
- Minimum-present hold and continuous-away confirmation to reduce false departures.
- Timed present and absent overrides while underlying evidence continues aging.
- Standard Presence Sensor capability plus arrival, departure and uncertainty button events.
- Transition history, evidence coverage, deadline countdown and ready-to-send notification text.
- Case-insensitive source matching with strict unknown-source rejection.
- Non-destructive test commands and automatically expiring debug logging.
